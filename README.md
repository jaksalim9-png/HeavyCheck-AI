# HeavyCheck AI — Starter Prototype

واجهة ويب عربية/فرنسية/إنجليزية كبداية لمشروع تشخيص المعدات الثقيلة:
- Clark forklifts
- Manitou telehandlers and material-handling equipment
- Excavators from multiple manufacturers

## ما الموجود في هذه النسخة؟
- لوحة تحكم متجاوبة للهاتف والحاسوب.
- صفحات المعدات والتشخيص وقاعدة الأعطال والمراجع.
- قاعدة JSON تجريبية صغيرة لأعراض عامة.
- محرك مطابقة كلمات مفتاحية لإظهار مسارات فحص أولية.
- تبديل واجهة العربية والفرنسية والإنجليزية.

## ما الذي لا تدّعيه النسخة؟
هذه ليست أداة تشخيص مصنع، ولا تتصل بوحدات ECU، ولا تقرأ كل رموز الأعطال، ولا تحتوي على مخططات مصنّعين أو قيم ضغط. لا تستخدم النتائج لاتخاذ قرار سلامة أو تشغيل. يلزم دليل الخدمة المطابق للموديل والرقم التسلسلي وفني مؤهل.

## التشغيل
لأن المتصفح قد يمنع `fetch()` عند فتح `index.html` مباشرة، شغّل خادماً محلياً من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح:
`http://localhost:8000`

أو ارفع المجلد إلى GitHub وشغّله عبر استضافة static مناسبة.

## خطة التطوير التالية
1. تعريف الشركات والموديلات والعائلات وأرقام PIN/serial بشكل منظم.
2. استيراد بيانات الأعطال من مصادر رسمية مرخصة والتحقق منها.
3. إضافة بحث حسب الشركة والموديل والمحرك ووحدة التحكم.
4. إضافة backend آمن وAPI للذكاء الاصطناعي، مع عدم إرسال أسرار API إلى المتصفح.
5. إضافة رفع الصور وتحليلها مع توضيح حدود الرؤية وعدم الجزم بالعطل.
6. إضافة دعم واجهات اتصال تشخيصية فقط بعد تحديد البروتوكولات والأجهزة المتوافقة.
7. إضافة صلاحيات المستخدمين وسجل تقارير وصيانة ونسخ احتياطي.

## حقوق البيانات
لا تنسخ أدلة الخدمة أو المخططات أو قواعد بيانات الشركات المصنعة دون إذن أو ترخيص. سجّل المصدر والإصدار والموديل لكل معلومة تقنية.
